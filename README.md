# Aura AI — Your Personal Life OS

A responsive, buildless dashboard with a warm ivory and amber interface. Open `dist/index.html`, or serve `dist` with any static HTTP server.

Includes task management, goals and progress, a calendar, daily mood check-ins, journal entries, a budget and expense log, personalized rule-based suggestions, and a 25-minute focus timer. Data is stored in this browser's localStorage. The initial entries are sample content. Profile name is editable.

This first version does not connect to a language model, bank account, or external calendar. There are no dependencies or build step. Google Fonts is optional; system fonts are used if unavailable.
